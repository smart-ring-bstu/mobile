# Smart Ring — Mobile

Мобильное приложение проекта Smart Ring (учебный проект БГТУ): одно кроссплатформенное приложение для умного кольца под Android и iOS.

**Стек:** Flutter (Dart).

> Проект в начале пути: каркас приложения пока не создан. Инструкция по запуску появится после его добавления.

## Ветки

- `main` — стабильная версия и деплой.
- `develop` — ветка для разработки, по умолчанию.
