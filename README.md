# Smart Ring — Mobile Application

Мобильное приложение проекта Smart Ring. Разрабатывается на Flutter с использованием языка Dart.

## О проекте

Smart Ring — проект программного комплекса для работы с данными умного кольца.

Мобильное приложение предназначено для подключения устройства, отображения показателей, просмотра истории измерений и синхронизации данных с сервером.

На текущем этапе подготовлен базовый Flutter-каркас приложения. Разработка функциональных возможностей будет выполняться постепенно.

## Технологии

- **Flutter** — фреймворк для разработки мобильного приложения.
- **Dart** — язык программирования.
- **Android** — поддерживаемая платформа.
- **iOS** — поддерживаемая платформа.

## Требования

Для разработки необходимы:

- Git.
- Flutter SDK.
- Dart SDK (устанавливается вместе с Flutter).
- Visual Studio Code или другая IDE с поддержкой Flutter.
- Android Studio и Android SDK для сборки и запуска Android-приложения.

Для сборки и запуска iOS-приложения необходимы macOS и Xcode.

Рекомендуемая версия Flutter на момент подготовки проекта: **3.47.8**.

Проверить установленные версии можно командами:

```bash
flutter --version
dart --version
flutter doctor
```

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/smart-ring-bstu/mobile.git
```

### 2. Переход в каталог проекта

```bash
cd mobile
```

### 3. Установка зависимостей

```bash
flutter pub get
```

### 4. Проверка доступных устройств

```bash
flutter devices
```

### 5. Запуск приложения

```bash
flutter run
```

Если подключено несколько устройств, Flutter может предложить выбрать устройство для запуска.
